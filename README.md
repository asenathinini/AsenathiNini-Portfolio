# Asenathi Nini — Digital Portfolio

A responsive personal portfolio for Semester 1 learning and Semester 2 PRP370 Entrepreneurial WIL evidence. Built with plain HTML, CSS and JavaScript; **npm install is not required**.

## Preview locally
Open `index.html` in your browser, or use the VS Code Live Server extension.

## Publish with GitHub Pages
1. Keep a backup of your existing Semester 1 portfolio before replacing or merging files.
2. Copy the website files (`index.html`, `style.css`, `script.js`, and `assets/`) into the root of the existing portfolio repository, merging rather than deleting any useful files.
3. Commit and push the changes to GitHub.
4. In the repository, open **Settings → Pages** and select the correct branch and `/ (root)` if your site files are in the repository root.
5. Open the published GitHub Pages URL and check every link on desktop and mobile.

## Before submitting
- Add verified evidence for User Stories & Tasks, Product Backlog, Sprint Backlog and Agile Logbook.
- Confirm the updated team charter accurately distinguishes original team membership from current participation.
- Verify the CV and mock interview links.
- Submit the **published GitHub Pages website URL**, not the repository URL.

The portfolio currently uses the personal and project information supplied by Asenathi. Review contact details and all claims for accuracy before publishing.
