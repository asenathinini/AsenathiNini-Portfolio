## 🚀 Semester 2 Project: UniWorks

### Project Overview

**UniWorks is a web-based student freelance marketplace developed as part of my academic project work.**

The platform aims to connect CPUT students with clients who need assistance with freelance and part-time work. It gives students an opportunity to showcase their skills and find work opportunities while allowing clients to post jobs and discover student talent.

### Main Objectives

- Connect students with clients offering work opportunities.
- Allow students to create profiles showcasing their skills.
- Enable clients to post jobs and review student applications.
- Provide a structured platform for managing job opportunities.
- Consider user privacy and safety when designing platform functionality.

### Agile Project Management

The UniWorks project uses Agile planning and documentation to organise requirements, development tasks, and project progress.

My project documentation includes:

- **Agile Team Charter:** Defines team expectations, responsibilities, communication, and ways of working.
- **User Stories:** Documents requirements from the perspectives of students, clients, and administrators.
- **Product Backlog:** Organises and prioritises the 35 user stories using the MoSCoW method.
- **Sprint Backlog:** Tracks planned tasks and development progress.
- **Agile Logbook:** Records project activities, progress, challenges, and reflections.
